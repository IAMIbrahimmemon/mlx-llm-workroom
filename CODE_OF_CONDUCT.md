# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## The longer version

This project follows the [Contributor Covenant][cc], version 2.1. In practice
that means harassment, personal attacks, and dismissive or demeaning comments
are not welcome here, and neither is publishing someone else's private
information.

Technical disagreement is fine and expected. Making it personal is not.

## Enforcement

Report problems to the maintainer through a private message or by opening an
issue if it is safe to do so publicly. Reports are handled privately, and the
maintainer may remove comments, close issues, or block accounts.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
